36°C Challenge - FarmShield NG

Climate-smart agriculture webapp for Nigerian farmers.
Helps with location-based weather, manual crop inputs, personalized advice on planting, irrigation, and resilience.

## Tech Stack
- Backend: Django + Django REST Framework
- Frontend: React JS (JavaScript)
